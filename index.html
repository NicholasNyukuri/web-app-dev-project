Internet Terminology Website

Intranet

An intranet is a private network within an organization used for internal communication and resources.

Extranet

An extranet is a private network that allows limited access to external users (e.g., partners, suppliers).

Multitier Architecture

A multitier architecture is a system design that separates applications into layers: Presentation layer (UI), Application layer (logic), and Data layer (database). It improves scalability and maintenance.

File Transfer Protocol (FTP)

The File Transfer Protocol is used to transfer files between computers over a network.

Hypertext Markup Language (HTML)

HTML is the standard language used to create web pages.

Web 1.0

Early web (1990s), static pages, read-only content. Users could only consume information.

Web 2.0

Interactive and social web with user-generated content such as blogs and social media (e.g., YouTube, Facebook).

Web 3.0

Intelligent and decentralized web using AI, blockchain, and semantic data for better personalization.

Web 4.0

Future web: fully intelligent, AI-driven, and highly connected with seamless human–machine interaction.
