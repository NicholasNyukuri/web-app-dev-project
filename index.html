Internet Terminology Website

Intranet An intranet is a private network within an organization used for internal communication and resources. Extranet An extranet is a private network that allows limited access to external users (e.g., partners, suppliers). Multitier Architecture A multitier architecture is a system design that separates applications into layers: Presentation layer (UI) Application layer (logic) Data layer (database) Improves scalability and maintenance. File Transfer Protocol (FTP) The File Transfer Protocol is used to transfer files between computers over a network. Hypertext Markup Language (HTML) The HTML is the standard language used to create web pages. Web 1.0 Early web (1990s) Static pages Read-only content Users could only consume information Web 2.0 Interactive and social web User-generated content (blogs, social media) Examples: YouTube Facebook Web 3.0 Intelligent and decentralized web Uses AI, blockchain, and semantic data Focus on personalization and machine understanding Web 4.0 Emerging concept (future web) Fully intelligent, AI-driven, and highly connected Seamless interaction between humans and machines
